# Oni City Hub

Build ONI HUB V3, starting ONLY with the production-quality HOME / ONI CITY experience. This is the official digital headquarters for the Mongolian CPM clan Oni And Kishin. The quality target is the premium cinematic presentation philosophy of Arknights: Endfield, but create a fully original ONI identity: do not copy Endfield artwork, characters, logos, text, or proprietary assets. Avoid a generic cyberpunk terminal, dashboard, card grid, or simple neon website. The first screen must feel like entering a AAA anime game world: fullscreen cinematic Japanese underground/JDM city environment, a prominent original anime-style character presentation, a premium modified JDM car integrated into the scene, layered city depth, atmospheric haze, wet reflections, restrained crimson lighting, and sophisticated game-HUD typography/navigation. Visual hierarchy matters more than excessive effects. Use black/midnight/white/crimson as the core palette. Motion should be subtle and expensive-looking: depth/parallax, atmospheric movement, small character/environment motion, elegant section transitions; no constant aggressive glitching. Mobile/iPhone is first-class and should be recomposed rather than merely shrunk. Primary interface language should be Mongolian, with small decorative English/Japanese-style labels only where they improve the game-world aesthetic. Use the correct clan identity Oni And Kishin and do not invent dates or statistics. Establish polished navigation destinations for HOME, CREW, GARAGE, MUSIC, JOIN, MEET, ONI AI, ADMIN, but do not spend effort building their full pages yet. Architect the project so existing Firebase/Firestore data, admin, members, garage, music, Oni Meet and ONI AI/ONI Brain functionality can be migrated later. The final web experience will become a PWA and eventually an iOS + Android app, so keep the foundation portable, responsive, accessible, performant and production-oriented. Do not hotlink copyrighted anime/game art. Create an original visual composition and intentional fallback/asset slots. The acceptance bar for this first build is that the HOME screen should immediately feel dramatically more premium, cinematic and game-like than a conventional clan website. Focus the available build effort on getting HOME right before anything else.
